# 지금 이 엔진이 못 하는 것 (지시서 §77)

> 마지막 갱신 2026-08-31 · 엔진 v0.15.0 · 테스트 1091개

이 문서는 변명이 아니라 **경계선**이다. 어디까지 믿어도 되는지 적어 둔 것이고,
여기 적힌 것을 모르고 결과를 쓰면 틀린 판단을 하게 된다.

---

## 1. 가장 큰 것 — 아직 실거래로 검증된 적이 없다

수집이 진행 중이다(2026-08-31 기준 매매 585,294건, 240개월 중 27개월).
지금까지의 모든 검증은 **합성 시장**에서 했다.

그래서 지금 나오는 점수는 **순위의 근거가 아니라 배관 검증 결과다.**

| 무엇 | 상태 |
|---|---|
| 코드가 도는가 | ✅ 합성 시장 3종(추세·가치·무신호)으로 확인 |
| 누출이 없는가 | ✅ 미래를 심어서 잡히는지까지 확인 |
| 점수가 맞는가 | ❌ **실거래로 검증된 적 없음** |
| 가중치가 맞는가 | ❌ 전부 `HEURISTIC`. 백테스트 학습 전 |

화면에 `⚠ 가중치 임시(heuristic)` 이 찍혀 있으면 그 뜻이다.

---

## 2. 검증할 수 **없는** 것 — 데이터 길이의 한계

보유기간을 검증하려면 겹치지 않는 검증 구간이 3개는 있어야 한다.
겹친 구간을 따로 세면 표본을 부풀리는 것이라 신뢰도가 가짜가 된다.

| 보유기간 | 검증에 필요한 구간 | 가능한가 |
|---:|---:|---|
| 2년 | 6년 | ✅ 학습 비율을 줄이면 |
| 5년 | 15년 | ❌ **불가능** |
| 10년 | 30년 | ❌ **불가능** |

국토부 실거래 공개가 2006년부터라 최대 20년이다.
**5년·10년 랭킹의 가중치는 정식으로 검증할 수 없다.** TRAIN 구간의 상관까지만
보고 가중치는 heuristic 을 유지한다. 이건 구현의 한계가 아니라 데이터의 한계라서
`backtest plan` 이 돌리기 전에 알려준다.

---

## 3. 대리지표 — 실측이 아닌 것

셋은 진짜로 재려면 없는 데이터가 필요해서 근사했다. 근사값이라 **신뢰도에
상한을 걸어 뒀고**, detail 에 그 사실이 적혀 있다.

| Feature | 진짜로 재려면 | 지금은 | 상한 |
|---|---|---|---:|
| `buyer_pool` | 소득·대출가능액 분포 | 거래 활성도 + 세대수 | 0.45 |
| `buyer_overlap` (Leader) | "이 단지 본 사람이 저것도 봤는가" | 생활권·가격대·면적대 | 0.80 |
| `next_node_score` | 생활권 가격 사다리 | **미입력** — 계산 안 됨 | — |

대리지표를 실측처럼 보여주지 않는 것이 이 상한의 목적이다.

---

## 4. 값이 없어 계산되지 않는 것

코드는 다 있고 데이터만 없다. 화면에 "확인 불가" 로 나온다.

| 무엇 | 없으면 | 채우는 법 |
|---|---|---|
| 생활권 가격 사다리 | Next Node · Money Arrival Depth 불가 | `ladder import` |
| 대지면적(건축물대장) | 재건축 사업성 **전부** 불가 | `redev import landarea` |
| 입주물량 | 공급 위험이 0 이 아니라 "확인 불가" | `supply import` |
| 교통사업 단계 | 촉매 알파 불가 | `transit import` |
| 과거 LTV·DSR·취득세 | **2017/2019/2021/2023 검사 불가** | `rules/loan.csv` 등에 그 시점 행 추가 |
| 현금 수익률 | CASH 순위를 만들지 않음 | `profile set --cash-hurdle` |
| 타입별 지속 격차 | Type 정규화 안 함 | `complex_type` (자동 생성 경로 없음) |

마지막 두 줄이 중요하다. **없으면 0 으로 가정하지 않는다.**
현금 수익률을 0% 로 두면 현금이 항상 최악이 되고, 타입 격차를 0 으로 두면
A타입과 B타입이 한 가격으로 눌린다.

## 5. 구조적으로 못 하는 것

### 5-1. 호가를 못 본다

실거래만 쓴다. 지금 시장에 나와 있는 물건의 호가는 수기 입력(`listing`)이
아니면 들어오지 않는다. 그래서 **"지금 이 가격에 살 수 있는가" 가 아니라
"최근에 이 가격에 팔렸다" 를 본다.** 급매 흡수(§35)로 일부 보정하지만
호가 자체를 대신하지는 못한다.

### 5-2. 전세 승계와 주담대를 동시에 못 쓴다

엔진이 조합 자체를 거부한다. 전세보증금이 선순위라 담보여력이 남지 않기
때문인데, 실제로는 후순위 대출이 나오는 경우가 있다. 지금은 그 경우를
다루지 않는다 — 각각의 최대치를 더해서 실투자금이 음수로 나오는 것보다는
거부하는 쪽이 낫다고 판단했다.

### 5-3. 단지 내 동·층·향을 구분하지 않는다

`complex_type` 표는 있지만 채우는 경로가 없다. 같은 84㎡ 안의 A타입/B타입
가격차를 지금은 한 값으로 눌러서 본다.

### 5-4. 사람의 판단이 필요한 것

- 재건축 정비계획·조합 상황 — 공시가 아니라 현장 정보다
- 학군·상권 변화 — 측정 가능한 형태로 들어와야 하는데 아직 없다
- 임장에서만 보이는 것 (관리상태·주차·소음)

---

## 6. 판정 기준 — 관측이 아닌 숫자들

아래는 전부 "이 정도면 그렇다고 보자" 로 정한 값이다. 관측된 분포가 아니다.
백테스트가 대체할 자리이고, 코드에 `THRESHOLD_NOTE` 로 표시해 뒀다.

| 어디 | 무엇 |
|---|---|
| `stretch.py` | 가속 구간별 남은 알파 (Emerging 1.00 · Overheated 0.10) |
| `bands.py` | 밴드 상승 1% · Spike 판정 (3M 10% vs 장기 2%) |
| `stage.py` | Cheap ≤ −3% · Expensive ≥ +10% · Moving ≥ 0.5 |
| `leader.py` | 전달실패 (Leader +8% · Follower +2% · 12개월) |
| `executable.py` | 시장온도 경계 (20% / 8% / 2%) |
| `frontier.py` | 문턱 판정 (점수 +3.0 · 자기자본 대비 +2%) |
| `rotation.py` | 회전 마진 5% · 의미 있는 순위 이동 3칸 |
| `sanity.py` | 2021 BUY 상한 20% · 2017/2019 하한 10% |

**이 값들이 결과를 바꾼다.** 지금 TOP10 을 투자 판단에 쓰면 안 되는 이유가
여기에도 있다.

---

## 7. 검증했지만 한계가 있는 것

### 7-1. 2021 검사는 True Blind Test 가 아니다

우리는 이미 2021 이 고점이었다는 것을 알고 검사를 설계했다(§28).
통과해도 "모델이 2021 을 예측했다" 로 읽으면 안 된다. 반대 방향
검사(2017/2019 를 놓치지 않는가)를 같이 걸어야 의미가 있다.

### 7-2. 합성 시장은 우리가 만든 시장이다

신호를 심고 그걸 찾는지 보는 것이라, "찾았다" 는 하네스가 작동한다는 뜻이지
실제 시장에서 통한다는 뜻이 아니다. 실제로 합성 시장을 만들면서 두 번
틀렸다 — "신호 없음" 모드에 신호가 있었고, 덧셈 잡음이 가짜 평균회귀를
만들었다. 지금은 고쳤지만, 같은 종류의 실수가 더 있을 수 있다.

## 8. 결론 — 지금 이걸로 무엇을 할 수 있나

| 할 수 있는 것 | 하면 안 되는 것 |
|---|---|
| 데이터가 무엇이 없는지 확인 | TOP10 을 투자 판단 근거로 사용 |
| 실투자금 계산 (규칙이 들어간 케이스) | 검증되지 않은 가중치의 점수를 신뢰 |
| 규제·세금 시점별 판정 | 5년·10년 랭킹을 검증된 것으로 취급 |
| 수집 후 백테스트를 바로 실행 | 대리지표를 실측처럼 인용 |

수집이 끝나면 이 순서다.

```bash
apt backtest plan  --start 2006-01-01 --end 2026-01-01 --horizon 2 --step 3 \
                   --train-frac 0.45 --val-frac 0.35
apt backtest run   ... --run-key wf1
apt backtest sanity              # 2017/2019/2021/2023 을 같은 가중치로
apt backtest weights --run-key wf1
apt today --cash 3 --weights backtested
```

마지막 줄에서 `⚠ 가중치 임시` 가 사라지면, 그때부터 이 문서의 1번이 바뀐다.
