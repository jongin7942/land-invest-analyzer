# 데이터 품질 (지시서 §77·§3·§36·§67)

> 마지막 갱신 2026-08-31

---

## 0. 원칙 — 품질은 Alpha 를 올리지 않는다

**데이터가 좋다는 이유로 점수가 오르지 않는다.** Confidence 만 오른다(§36).

이게 중요한 이유: 데이터가 잘 갖춰진 지역(서울 등)이 자동으로 높은 점수를
받게 되면, 그건 투자 판단이 아니라 **데이터 수집 편향**이다. §33 이 금지한
"지역명에 점수 주기" 가 다른 경로로 들어오는 셈이다.

---

## 1. 못 구한 값의 표현

**절대 0 으로 채우지 않는다.**

| 상황 | 표현 |
|---|---|
| 값이 없다 | `Feature.missing(key, 사유)` → `value=None` |
| 값은 있는데 표본이 부족 | `status=LOW_CONFIDENCE`, `usable=False` |
| 제도상 확인이 안 됐다 | `verification=NEEDS_VERIFICATION` |
| 계산했는데 못 냈다 | 스키마 CHECK 가 `unknown_reason` 을 요구 |

화면에는 "없음" 이 아니라 **"확인 불가" + 사유**로 나간다.

```
supply_ratio_2y: 확인 불가 — 입주물량 데이터가 없습니다
```

"없음" 은 "공급이 0" 으로 읽히고, 그건 좋은 신호다. 실제로는 모르는 것인데.

---

## 2. 신뢰도를 만드는 것

| 원천 | 함수 |
|---|---|
| 표본 수 | `sample_confidence(n, full_at=...)` |
| 최신성 | `freshness_confidence(months_old, half_life=6)` |
| 모델 커버리지 | 9모델 중 계산된 비율 |
| 이웃 확인 · 경로 · Reset 단계 | §10 — Alpha 가 아니라 여기로 |

합칠 때 **기하평균**을 쓴다. 가장 약한 것이 전체를 끌어내린다.

`usable` 은 0.35 이상일 때만 참이다. 그 아래는 값이 있어도 안 쓴다.

---

## 3. 대리지표 — 실측이 아닌 것

셋은 진짜로 재려면 없는 데이터가 필요해서 근사했고, **신뢰도에 상한을 걸었다.**

| Feature | 진짜로 재려면 | 근사 | 상한 |
|---|---|---|---:|
| `buyer_pool` | 소득·대출가능액 분포 | 거래 활성도 + 세대수 | 0.45 |
| `buyer_overlap` | 행동 데이터 | 생활권·가격대·면적대 | 0.80 |
| `type_gap_pct` | 타입별 거래 이력 | **없음 — 보정 안 함** | — |

상한의 목적은 하나다. **근사값이 실측처럼 보이지 않게 하는 것.**

## 4. 가격 데이터의 품질

### 걸러내는 것 (`price/outlier.py`)

| hard — 어떤 경우에도 시세가 아니다 | soft — 표본이 모자라면 되살린다 |
|---|---|
| 취소(해제)된 거래 | 1층 이하 특수층 |
| 직거래 (특수관계인 가능성) | 갱신요구권 사용 갱신계약 |
| 월세 낀 계약(전세 아님) | 통계적 이상치 (수정 z-score 3.5) |

soft 를 되살리면 **되살렸다는 사실이 계산근거에 남는다.** 화면에서
"이 가격은 1층 거래까지 포함한 값" 이라고 말할 수 있다.

### 대표가격 신뢰도

| 등급 | 정상거래 |
|---|---:|
| HIGH | 10건 이상 |
| MEDIUM | 3~9건 |
| LOW | 1~2건 |

**신뢰도와 등급은 다른 축이다.** 1~2건으로 낸 가격도 실거래에서 나온 값이라
등급은 CONFIRMED 이고 신뢰도만 LOW 다. 추정으로 만든 값(ESTIMATED)과
표본이 적은 실측값을 섞으면 안 된다.

## 5. 출처 충돌 (§3)

같은 필드에 다른 값이 오면 **덮어쓰지 않는다.** `source_conflict` 에 둘 다
남기고, 등급이 낮은(=더 공식적인) 쪽을 채택한다.

**등급이 같으면 자동으로 고르지 않는다.** `resolved_to=NULL` 로 두고
"사람이 확인하세요" 를 남긴다.

## 6. 단지 매칭

실거래 API 는 단지명을 문자열로 준다. K-apt 마스터와 붙여야 하는데 표기가
다르다.

```
부개주공3        ↔  부개주공3단지
주공5(부개동)     ↔  부개 주공5단지
동아(1차)        ↔  부평 동아1단지
SK Sky VIEW      ↔  에스케이스카이뷰
```

표기 변형 계층을 추가해 미매칭 **49% → 26%**, WEAK 매칭 3,117 → 224건.

매칭 등급은 `EXACT / STRONG / WEAK / NONE` 이고 `match_reason` 이 붙는다.
WEAK 는 가격 계산에 쓰지만 그 사실이 근거에 남는다.

미매칭 목록: `apt report unmatched --limit 100`
