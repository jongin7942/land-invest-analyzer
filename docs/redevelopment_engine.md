# 재건축 엔진 (지시서 §77·§19~§22·§34)

> 마지막 갱신 2026-08-31

---

## 0. 고정점수를 주지 않는다

"재건축 가능성 있음 → +10점" 은 §49-9 위반이다.

프리미엄이 1억 붙었는데 기대 순이익이 5억이면 좋고, 프리미엄이 4억 붙었는데
순이익이 3억이면 사면 안 된다. **같은 "재건축 호재" 인데 정반대 판단이다.**

---

## 1. 순서 (§34)

```
① NakedApartmentValue         재건축을 빼고, 그냥 낡은 아파트로서의 값
② ImpliedReconstructionPremium = 현재가 − ①
                                 시장이 재건축에 얹어 놓은 금액
③ PremiumEfficiency = 기대 순가치(현재가치) ÷ ②
```

③이 1보다 크면 프리미엄이 싸고, 작으면 이미 비싸다.

### ①이 가장 어렵다

"재건축을 뺀 값" 은 관측되지 않는다. 그래서 **비교 단지에서 빌려 온다** —
같은 생활권·같은 면적·비슷한 연식인데 **재건축 기대가 없는** 단지의 ㎡당 가격.

조건이 셋이다.

```
재건축 기대가 없는 단지여야 한다
비교 단지가 3개 이상이어야 한다
연식 차이가 8년 이내여야 한다     (넘으면 상품성이 다르다)
```

**못 찾으면 추정하지 않는다.** NakedValue 가 없으면 프리미엄도 효율도 없다.

---

## 2. 시간가치를 반드시 반영한다

```
기대 순가치(현재가치) = 기대 총가치 ÷ (1 + 할인율)^완공까지연수
```

**할인율을 모르면 계산하지 않는다.** 0% 로 두면 20년 뒤 5억이 지금 5억이 되어
**모든 노후 단지가 좋아 보인다.** 재건축 분석에서 가장 흔한 착시다.

같은 기대가치라도 5년 뒤와 25년 뒤는 완전히 다른 투자다.

---

## 3. Bear / Base / Bull (§19)

용적률·분담금·기간을 세 시나리오로 본다. 결과는 `redevelopment_scenario` 에
저장되고 **`data_grade` 가 `'SCENARIO'` 로 고정**돼 있다 — 스키마 CHECK 다.
시나리오 값이 실측으로 둔갑할 수 없다.

---

## 4. 용적률은 네 종류다

| 종류 | 뜻 |
|---|---|
| 법정상한 | 국토계획법상 최대 |
| 조례 | 지자체가 정한 것 |
| 정비계획 | 이 사업에 실제로 부여된 것 |
| 역세권특례 | 조건부 상향 |

**현재 용적률(`complex.current_far`)은 이 중 어느 것도 아니다.** 지금 지어져
있는 것일 뿐이다. 넷을 섞으면 사업성이 통째로 틀린다.

그리고 `planned_far`(정비계획 용적률)는 **정비구역 지정 이후에만** 넣을 수
있다 — 스키마 CHECK 다. 지정 전에는 그런 숫자가 존재하지 않는다.

---

## 5. Time Arbitrage (§21)

```
시장이 예상하는 기간  vs  우리가 보는 기간
```

시장이 20년으로 보는데 실제로 10년이면 그 차이가 알파다. 반대면 함정이다.

단계별 소요기간(`stage_duration_ref`)이 있어야 계산되는데 **지금 비어 있다.**
없으면 "사업기간 확인 불가" 다.

---

## 6. Reconstruction Ablation (§22)

재건축 기대를 **빼고** 점수를 다시 매긴다. 그래도 상위면 재건축은 덤이고,
재건축을 빼니 순위가 급락하면 그 후보는 **재건축 하나에 걸린 것**이다.

`scoring/thesis.py` 의 Thesis Survival 이 같은 원리다.

---

## 7. 1차 스크리닝은 금액을 만들지 않는다

```bash
apt redev screen --limit 100
```

연식·용적률·대지지분만 본다. **금액 추정을 하지 않는다** — 대지면적이
없으면 사업성 숫자는 전부 거짓이 되기 때문이다.

상위 50~100개만 골라 건축물대장·정비계획을 수기로 채우면 된다.

---

## 8. 지금 상태

**대지면적이 없어 재건축 사업성이 전부 계산되지 않는다.**

K-apt 기본정보에 대지면적이 없다. 건축물대장이나 V-World 에서 따로 채워야 한다.

```bash
apt redev template landarea rules/landarea.csv
apt redev import landarea rules/landarea.csv
```

평균 대지지분 = 대지면적 ÷ 세대수. 이 값 없이는 ①부터 안 된다.
