# 링크로 공유하기

카톡에 링크를 붙여 남이 열어 볼 수 있게 하는 방법. **두 가지**가 있고,
둘 다 준비돼 있다.

---

## 먼저 알아야 할 것 세 가지

### ① 지금 공유하면 잠금 화면이 나갑니다

가중치를 백테스트로 학습하기 전이라 순위가 잠겨 있습니다. 링크를 받은
사람은 **"순위는 아직 잠겨 있습니다"** 화면을 봅니다.

공개 모드에서는 `?unlock=1` 우회도 막습니다. 그 화면은 스스로
"이 순위는 투자 판단 근거가 아닙니다" 라고 밝히는 화면인데, 주소에
파라미터 하나 붙여서 닿을 수 있으면 우리가 안 된다고 적어 둔 것을
주소창으로 우회하게 두는 셈이기 때문입니다.

**지금 공유해서 쓸모 있는 화면**은 잠금과 무관하게 도는 쪽입니다 —
단지 검색 · 대표가격 · 실투자금 계산 · 단지 비교 · 데이터 현황.

### ② 아는 사람 몇 명에게만 보내는 전제입니다

초대한 사람만 들어올 수 있게 잠가 두면, 불특정 다수에게 서비스하는
것이 아니라 **내가 만든 것을 아는 사람에게 보여주는 것**입니다.
공개 서비스로 키울 생각이면 그때 공공데이터포털 오픈API 이용약관을
다시 보세요.

### ③ 초대하지 않으면 주소를 아는 누구나 들어옵니다

`trycloudflare.com` 주소는 추측하기 어렵지만, 카톡 링크는
**전달되고 캡처됩니다.** 아래 초대를 먼저 만드세요.

---

## 먼저 — 볼 사람을 정한다 (한 번만)

```bash
python -m apt_engine.cli invite add 철수 --note "고등학교 친구"
python -m apt_engine.cli invite add 영희
```

사람마다 **다른 코드**가 나옵니다. 공용 비밀번호 하나를 단톡방에 뿌리는
것과 다른 점이 여기 있습니다.

| | 공용 비번 하나 | 사람마다 초대 |
|---|---|---|
| 하나가 새면 | 전부 바꾸고 전부에게 다시 보내야 함 | **그 한 명만 끊음** |
| 누가 들어왔나 | 알 수 없음 | 이름·방문 횟수·마지막 접속 |
| 나중에 다시 보내기 | 기억에 의존 | `invite links` |

```bash
python -m apt_engine.cli invite list              # 누가 들어왔는지
python -m apt_engine.cli invite revoke 철수        # 철수만 끊기 (나머지는 그대로)
python -m apt_engine.cli invite restore 철수       # 다시 열어주기
python -m apt_engine.cli invite links --url https://xxx.trycloudflare.com
```

**한 명이라도 초대하면 그때부터 잠깁니다.** 초대가 하나도 없으면 잠기지
않습니다 — 내 PC 에서 혼자 보는 평소 상태입니다.

> **전부 끊으면 아무도 못 들어옵니다.** 마지막 한 명을 끊었을 때 잠금이
> 사라지면, 모두를 내보내려던 행동이 모두를 들여보내는 결과가 됩니다.
> 끊는 것과 잠금을 푸는 것은 다릅니다.

초대 정보는 `access.db` 에 따로 저장됩니다(커밋되지 않습니다). 수집이
계속 쓰고 있는 `apt_invest.db` 를 건드리지 않으려고 파일을 나눴습니다.

## 방법 A — 지금 당장 (내 PC + 터널)

공유기 설정도, 공인 IP 도, 비용도 필요 없습니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\share.ps1
```

주소를 받아서 **사람마다 다른 링크를 만들어 화면에 찍어 줍니다.**
그대로 각자에게 카톡으로 보내면 됩니다.

```
==============================================================
 아래 링크를 각자에게 카톡으로 보내세요 (사람마다 다릅니다)
==============================================================

철수
https://xxxx.trycloudflare.com/?code=VrtCnXkdponH

영희
https://xxxx.trycloudflare.com/?code=VUOJjWTIvE2D
```

받은 사람이 링크를 누르면 코드가 쿠키로 옮겨지고 **주소창에서는
지워집니다** — 그 사람이 주소를 그대로 다시 공유해도 코드가 안 딸려
갑니다.

순위 화면(잠금 우회)까지 보여주려면 `-ShowRankings` 를 붙이세요.
"투자 판단 근거가 아닙니다" 경고 배너는 그대로 나갑니다.

| | |
|---|---|
| 준비 시간 | 1분 |
| 비용 | 0원 |
| 조건 | **이 PC 가 켜져 있어야 합니다.** 끄면 링크도 죽습니다 |
| 주소 | 실행할 때마다 **바뀝니다** (고정 주소는 Cloudflare 계정 필요) |

맥·리눅스는 `./scripts/share.sh [접속코드]`.

> 수집이 도는 중에도 됩니다. 화면은 읽기 전용으로 DB 를 열기 때문에
> 수집을 방해하지 않습니다. 다만 PC 가 바빠서 화면이 느려질 수는 있습니다.

## 방법 B — 항상 켜진 링크 (클라우드)

PC 를 꺼도 살아 있고 주소가 고정됩니다. `Dockerfile` 과 `fly.toml` 이
들어 있습니다.

```bash
fly launch --no-deploy                       # fly.toml 을 그대로 씁니다
fly volumes create aptdata --region nrt --size 10
fly deploy
fly ssh sftp shell                           # DB 업로드
  put apt_invest.db /data/apt_invest.db
fly secrets set APT_ACCESS_CODE=우리집비번    # (선택)
fly secrets set APT_SITE_URL=https://apt-invest.fly.dev
```

도쿄(`nrt`)를 쓰는 이유는 한국에서 가장 가까워서입니다.

| | |
|---|---|
| 준비 시간 | 30분 + DB 업로드 |
| 비용 | 볼륨 10GB + 머신. 아무도 안 보면 재우도록(`auto_stop_machines`) 해 뒀습니다 |
| 갱신 | 수집이 진행되면 **DB 를 다시 올려야** 최신이 됩니다 |

DB 를 이미지에 굽지 않는 이유: 수집이 끝나면 수 GB 인데, 이미지에 넣으면
코드 한 줄 고칠 때마다 그걸 다시 올려야 합니다.

## 공개 모드가 하는 일

`APT_PUBLIC=1` 이면 (두 방법 모두 자동으로 켭니다):

- `?unlock=1` 잠금 우회를 **받지 않습니다**
- `X-Robots-Tag: noindex` — 검색엔진에 색인되지 않습니다.
  이 화면의 숫자는 수집 진행도에 따라 바뀌는데, 검색결과에 옛날 순위가
  남으면 그게 사실처럼 읽힙니다
- 클릭재킹 방지(`X-Frame-Options`), MIME 스니핑 방지 헤더

환경변수:

| 변수 | 뜻 |
|---|---|
| `APT_PUBLIC=1` | 공개 모드 |
| `APT_ACCESS_CODE` | 모두가 같이 쓰는 코드 (초대를 쓰면 필요 없음) |
| `APT_ACCESS_DB` | 초대 파일 경로 (기본 `access.db`) |
| `APT_ALLOW_UNLOCK=1` | 공개 상태에서도 잠금 우회를 허용 |
| `APT_SITE_URL` | 배포 주소. **넣어야 카톡 미리보기 이미지가 나옵니다** |
| `APT_SITE_NAME` | 링크 카드에 뜨는 이름 |
| `PORT` / `THREADS` | 포트, 동시 처리 스레드 (기본 5001 / 8) |

## 카톡 링크 미리보기

`static/og.png` (1200×630) 과 `og:` 태그가 붙어 있어서 카톡에 붙이면
제목·설명·이미지가 카드로 나옵니다.

**카카오톡은 미리보기를 캐시합니다.** 내용을 바꿨는데 옛날 카드가 계속
나오면 [카카오 개발자 도구](https://developers.kakao.com/tool/clear/og)
에서 캐시를 지우세요.

미리보기 이미지가 안 나오면 `APT_SITE_URL` 이 비어 있는 것입니다 —
카톡은 상대경로 이미지를 못 읽어서 절대주소가 필요합니다.

## 서버

`python apt_app.py` 의 Flask 개발 서버는 한 번에 한 요청만 제대로
처리합니다. 여러 명이 들어오면 줄을 세워서, 한 사람이 순위를 계산하는
동안 나머지는 빈 화면을 봅니다. 공유할 때는 `python serve.py` 를 쓰세요
(위 스크립트들은 이미 그렇게 합니다).

waitress 를 쓰는 이유는 **윈도우에서 돌기 때문**입니다. gunicorn 은
윈도우를 지원하지 않습니다.
