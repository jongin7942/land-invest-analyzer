## J. 주변 대표 신축가 — **API 필요 없음. 제가 구현했습니다** ✅

지시서 §27 의 "완공 후 예상가치 = 주변 신축 미래가격 × 품질 반영률" 에서
**'주변 신축' 은 이미 우리 DB 에 있습니다.**

| 필요한 것 | 어디서 | 상태 |
|---|---|---|
| 준공연도 | K-apt 기본정보 `AptBasisInfoService` | **이미 수집 중** |
| 좌표 | V-World 지오코딩 | **이미 수집 중** (`cli geocode`) |
| 가격 | 국토부 실거래 대표가격 | **이미 수집 중** |

`apt_engine/redev/peer_new.py` 가 반경 2km · 준공 7년 이내 · 표본 5건 이상
중에서 **가장 비싼 단지**를 대표 신축으로 잡습니다. 좌표가 없으면 같은
법정동으로 좁힙니다(시군구 전체로 넓히면 압구정 신축을 개포동 재건축의
기준으로 쓰게 됩니다).

**종인님이 하실 일**: 좌표만 채우면 됩니다.

```powershell
python -m apt_engine.cli geocode --limit 500
```

> 단, **미래가격 상승률**은 여전히 가정입니다. 모르면 완공가치를 계산하지
> 않습니다 — 임의로 연 3% 를 박으면 정비사업 기대수익 전체가 그 가정
> 위에 서게 됩니다.

## I. 지역 소득·고용 — KOSIS OpenAPI

### 키 발급 (무료 · 자동승인)

1. [kosis.kr/openapi](https://kosis.kr/openapi/index/index.jsp) 회원가입 → 로그인
2. 상단 **Open API → 활용신청** → 용도·서비스명 입력 → 신청
3. **자동 승인**됩니다. 마이페이지 → 인증키 확인에서 복사

`.env` 에 넣어 주세요:

```
KOSIS_API_KEY=발급받은키
```

### 엔드포인트

```
https://kosis.kr/openapi/Param/statisticsParameterData.do
  ?method=getList
  &apiKey=...
  &orgId=101          # 통계청
  &tblId=...          # 통계표 ID
  &itmId=...          # 항목
  &objL1=ALL          # 분류1 (시군구)
  &prdSe=Y            # 수록주기 (Y=연, Q=분기, M=월)
  &startPrdDe=2015&endPrdDe=2026
  &format=json&jsonVD=Y
```

⚠ **`tblId` · `itmId` · `objL1` 조합이 통계표마다 다릅니다.** 손으로
맞추기 어려우니 KOSIS 웹에서 원하는 표를 띄운 뒤 **`URL 생성`** 기능으로
주소를 뽑아 주시는 게 가장 빠릅니다. 그 URL 을 저에게 보내 주시면 제가
수집기로 만들겠습니다.

### 어떤 표가 필요한가 (가중치 순)

| 지표 | 가중치 | 통계 | 왜 |
|---|---|---|---|
| 고용자수 | 1.00 | 사업체노동력조사 (시군구별 종사자수) | 일자리가 늘면 오래 간다 |
| 고소득일자리 | 0.90 | 지역별 임금 분포 | 살 수 있는 가격대가 올라간다 |
| 사업체수 | 0.70 | 전국사업체조사 | |
| 평균소득 | 0.70 | 국세청 시군구별 근로소득 ([국세통계포털](https://tasis.nts.go.kr)) | KOSIS 아님 |
| 산업단지가동 | 0.50 | 한국산업단지공단 (공공데이터포털) | |
| 성과급 | 0.30 | 뉴스 | 한 해짜리라 낮게 봅니다 |

**전부 넣을 필요 없습니다.** 고용자수 하나만 있어도 계산은 되고,
지표가 적으면 신뢰도가 낮게 잡힙니다(1개 50% → 3개 90%).

### ⚠ 넣을 때 주의

- **출처(`source_name`)와 기준일(`observed_on`)이 없으면 DB 가 INSERT 를
  거부합니다.** 추정치를 넣으면 "삼성이 있으니 오른다" 는 이름값 점수가
  되기 때문입니다(§49-3).
- `last_verified` 가 비면 **계산에 쓰지 않습니다.**
- 24개월 지난 자료는 자동으로 빠집니다.
- 소득통계는 **발표 시차**가 있습니다. 백테스트가 미래를 안 보도록
  `as_of_ym` 은 **관측 시점**(그 통계가 다루는 기간)으로 넣어 주세요.

## H. 토지거래허가구역 — **통합 API 가 없습니다. 수기 입력**

찾아봤지만 전국 토허를 한 번에 주는 공공 API 가 없습니다. 지정 주체가
국토부·시도지사로 갈리고 **고시 단위**라서 그렇습니다. 실질적인 출처:

| 지역 | 출처 |
|---|---|
| 서울 | [서울부동산정보광장 — 토지거래허가구역 지정현황](https://land.seoul.go.kr/land/other/appointStatusSeoul.do) |
| 경기 | [경기부동산포털 — 토지거래허가구역](https://gris.gg.go.kr/gnPlan/selectLandTransactionZone.do) |
| 인천 | 인천시 고시 |
| 전국 | 국토교통부 보도자료·고시 |

```powershell
python -m apt_engine.cli rule template permit rules\permit.csv
python -m apt_engine.cli rule import permit rules\permit.csv
```

### 반드시 지킬 것

- **`target_scope` 에 내국인 / 외국인을 절대 혼동하지 마세요.**
  수도권 외국인 토허는 내국인 매수를 막지 않습니다. 섞으면 살 수 있는
  것을 못 산다고 말하게 됩니다.
- `effective_to`(종료일)를 **반드시** 적어 주세요. 만료된 지정을
  계속 적용하면 안 됩니다.
- `residence_duty_months` 가 비면 그 구역은 **NEEDS_CHECK 로 막힙니다.**
  Gate 는 확인 못 한 것을 통과시키지 않습니다.
- **시·구 전체가 비토허라고 개별 개발사업 구역까지 비토허는 아닙니다.**
  그래서 `parcel_recheck_required` 가 기본 1 입니다 — 매수 직전에
  필지 기준으로 다시 봐야 합니다.

> **인천 토허가 2026-08-25 에 만료**됐습니다. 재지정 여부 확인이 필요합니다.
