기준: 2026-08-31 · 엔진 v0.9.1 · 브랜치 `claude/new-program-development-f7gi4z`

> 2026-08-31 종인님이 직접 제공·검증한 값을 전부 반영했다.
> 이 문서는 **아직 남은 것**과 **그것 때문에 무엇이 막히는지**를 정리한다.

## 0. 신뢰도 두 축

| `status` | 뜻 | 계산 |
|---|---|---|
| `ENACTED` | 시행 중 | **금액에 들어간다** |
| `ANNOUNCED` · `PROPOSED` | 발표·입법예고 | "향후 정책 변경 가능" 안내로만 |
| `EXPIRED` | 시행 종료 | 백테스트에만 |

| `verification` | 뜻 | 계산 |
|---|---|---|
| `VERIFIED` | 원문 확인 | 실투자금이 **'확정'** 이 될 수 있다 |
| `ESTIMATED` | 사전 확정 불가한 추정치 (법무보수·채권 할인차손) | 쓰되 **'예상'** |
| `NEEDS_VERIFICATION` | 값은 있으나 원문 확인 전 | 쓰되 **'예상'** |
| `UNKNOWN` | 값이 없다 | **계산에 넣지 않는다.** 0원으로 세지 않는다 |

## 2. 아직 남은 것

### 2-1. LTV — 비규제지역 · 생애최초 · 다주택 ★가장 큰 구멍

규제지역 무주택/처분조건부 1주택(40%)만 받았다. 나머지 조건에서는 `LTV 한도` 가
**확인 불가**로 나온다.

| 막히는 것 | 실제 영향 |
|---|---|
| 비규제지역 전부 | LTV 없이 DSR·절대한도만으로 최종 한도가 정해진다 |
| 규제지역 1주택(처분조건 없음) | 〃 |
| 규제지역·비규제 다주택 | 〃 |
| 생애최초 | 우대 LTV 가 반영되지 않아 대출이 과소평가된다 |

LTV 를 못 구하면 엔진은 **담보가액(집값)** 을 산술적 상한으로만 쓴다.
이건 정책이 아니라 "집값보다 많이 빌릴 수는 없다"는 산술이고, 결과에
그 사실이 표시된다. 실제 대출은 이보다 훨씬 작으므로 **실투자금이 실제보다
작게 나올 수 있다.**

```csv
# rules/loan.csv 의 주석 행에서 '#' 을 지우고 value 만 채우면 됩니다
#ltv/비규제/무주택,LTV,<value>,,,0,무주택,,0,...
#ltv/생애최초,LTV,<value>,,,,,1,0,...
#ltv/규제지역/다주택,LTV,<value>,,,1,다주택,,0,...
```

### 2-2. 중과세율 건의 지방교육세

취득세 중과(8% / 12%) 건의 지방교육세 산식을 받지 못했다.
**CASE 4·5·6 에서 지방교육세가 "확인 불가"** 로 나온다(0원으로 세지 않는다).
일반세율 건(CASE 1·2·3)은 정상 계산된다.

### 2-3. 농어촌특별세 85㎡ 초과 세부 산식

종인님 지시대로 기존 0.2% 규칙을 유지하되 `NEEDS_VERIFICATION` 으로 뒀다.
특히 **중과세율(8%/12%) 적용 건에서 농특세 산식이 다를 수 있다** —
지금은 중과 건에도 0.2% 가 적용된다.

### 2-4. 법무·등기 실비 3종

`국민주택채권` · `등기신청수수료` · `증명서발급` 이 비어 있어 모든 CASE 에서
확인 불가 3건이 남는다. 그래서 실투자금이 **'확정'이 아니라 '예상'** 이다.

- 국민주택채권 할인차손은 할인율이 매일 변하므로 `ESTIMATED` 가 정답이다
- 등기신청수수료·증명서발급은 정액이라 `VERIFIED` 로 넣을 수 있다

### 2-5. 양도소득세 · 지방소득세

없으면 매도비용이 확인 불가라 **EXPECTED_ROE 가 나오지 않는다**.
랭킹에서 그 단지는 `comparable=False` 로 빠진다.

### 2-6. 재산세 · 종합부동산세

PHASE 7 현금흐름·보유비용에 필요하다.

### 2-7. 서울·경기 중개보수 조례

지금 들어 있는 건 인천뿐이다. 서울·경기 물건은 중개보수가 확인 불가다.

### 2-8. 생애최초 취득세 감면 · 감면분 농특세

감면 규칙 구조(`취득세감면` 세목 + `rule_key` 에 '감면' 이 든 농특세 행)는
만들어 뒀고 테스트도 있다. 값만 넣으면 동작한다.

## 3. 시행일 관련 주의 두 가지

### 3-1. 취득세·지방교육세는 2026-07-01 부터다

종인님이 확인한 지방세법 시행일(2026-07-01)을 `effective_from` 에 넣었다.
**그 이전 시점을 백테스트하면 "규칙 없음 → 확인 불가"** 가 나온다.
2021년 물건을 분석하려면 그 시점의 세법을 별도 행으로 추가해야 한다.

### 3-2. 10.15 대책 관련 규칙의 시행일은 추정이다

LTV 40% 와 스트레스 DSR 300bp 의 정확한 시행일을 받지 못해,
같은 대책의 절대한도 시행일(2025-10-16)을 따라 적었다.
각 행 `note` 에 `★시행일은 10.15 대책 기준으로 적었습니다` 로 표시돼 있다.
정확한 날짜가 다르면 `effective_from` 만 고치면 된다.

## 4. 실투자금 계산이 지금 막히는 항목 (요약)

| 항목 | 상태 | 결과 |
|---|---|---|
| 매수가 · 취득세 · 지방교육세(일반) · 농특세 · 인지세 · 중개보수 · 중개VAT · 법무보수 · 법무VAT | 계산됨 | — |
| 국민주택채권 · 등기신청수수료 · 증명서발급 | **UNKNOWN** | 합계에서 빠짐 → "N억 이상" |
| 지방교육세(중과 건) | **UNKNOWN** | CASE 4·5·6 에서 빠짐 |
| LTV 한도(비규제·다주택·생애최초) | **UNKNOWN** | 담보가액이 대신 상한이 됨 |

→ 지금은 모든 케이스가 **"예상 실투자금"** 이다.
2-4(실비 3종)만 채우면 일반세율 케이스는 **"실투자금 확정"** 이 된다.

## 5. 채운 뒤 하는 일

```bash
# rules/*.csv 에서 '#' 을 지우고 값을 채운 뒤
python -m apt_engine.cli rule import loan rules/loan.csv
python -m apt_engine.cli rule status          # 원문확인·시행전 개수까지 보인다
python -m pytest tests/test_finance.py -q     # CSV 를 직접 검증하는 테스트가 있다

# 값은 맞는데 확인 표시만 올리는 경우
python -m apt_engine.cli rule verify tax --id 7 --date 2026-09-01
```

`rule import` 는 INSERT 라 같은 파일을 두 번 넣으면 행이 중복된다.
다시 넣을 때는 해당 표를 비우거나 새 행만 담은 파일을 넣으세요.
