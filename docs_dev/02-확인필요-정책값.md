# 아직 VERIFIED 가 아닌 정책값 — 종인님이 직접 확인해야 하는 것

기준: 2026-08-30 · 엔진 v0.9.0 · 브랜치 `claude/new-program-development-f7gi4z`

> 이 문서는 "지금 프로그램이 무엇을 모르는가"의 전체 목록이다.
> 여기 있는 값을 채우면 실투자금이 **'예상'에서 '확정'으로** 바뀐다.
>
> **왜 Claude 가 채우지 않았나:** 이 작업 환경의 네트워크 정책이 `law.go.kr`,
> `easylaw.go.kr`, `casenote.kr` 등 법령 원문 사이트를 차단한다(egress proxy).
> 웹검색으로 나온 블로그·계산기 페이지는 공식 출처가 아니라, 지시문의
> *"검증되지 않은 정책 숫자를 임의로 만들어 넣지 마라"* 에 따라 입력하지 않았다.

---

## 0. 신뢰도 표시가 무슨 뜻인가

| 값 | 뜻 | 엔진 동작 |
|---|---|---|
| `VERIFIED` | 사람이 원문을 확인함 | 계산에 쓰고, 실투자금이 **'확정'** 이 될 수 있다 |
| `ESTIMATED` | 사전에 확정 불가한 실비 (채권 할인차손 등) | 계산에 쓰되 **'예상'** 표시 |
| `NEEDS_VERIFICATION` | 값은 있으나 원문 확인 전 | 계산에 쓰되 **'예상'** 표시 |
| `UNKNOWN` | 값이 없다 | **계산에 넣지 않는다.** 0원으로 세지 않는다 |

`status` 는 다른 축이다 — `ENACTED`(시행 중) 만 금액에 들어가고,
`ANNOUNCED`/`PROPOSED` 는 "향후 정책 변경 가능" 안내로만 나온다.

---

## 1. 값이 아예 없어 계산이 막히는 것 (UNKNOWN)

이걸 채우기 전에는 그 항목이 실투자금 합계에서 **빠진 채** "N억 이상" 으로만 나온다.

### 1-1. 대출 규칙 — `rules/loan.csv` (활성 0건) ★최우선

없으면 **대출 가능액이 통째로 확인 불가**고, 실투자금도 확정되지 않는다.
`rule_type` 별로 한 행씩 적는다. 파일 안에 주석으로 넣을 자리를 다 만들어 뒀다.

| rule_type | 필요한 값 | 어디서 |
|---|---|---|
| `LTV` | 무주택/1주택/다주택 × 규제/비규제 × 생애최초 별 비율 | 금융위원회 보도자료, 은행업감독규정 |
| `DSR` | 비율 (보통 40%) | 금융위 감독규정 |
| `STRESS_DSR` | 가산금리 **bp** (예: 150 = 1.5%p) | 금융위 스트레스 DSR 보도자료 |
| `MORTGAGE_CAP` | 대출 총액 상한 (원) | 금융위 보도자료 |

시행일(`effective_from`)을 반드시 적어야 백테스트가 맞는다.
**정책이 바뀌면 기존 행을 고치지 말고 `effective_to` 를 채운 뒤 새 행을 추가**한다.

### 1-2. 법무사 보수표 — `rules/cost.csv` 의 `법무비` (0건)

소유권이전등기 **기본보수**를 부동산 가액 구간별로. 출처: 대한법무사협회 보수표.
`fixed_amount` 에 정액을 넣으면 된다. 지금은 "법무·등기비 예상액" 전체가 확인 불가다.

### 1-3. 법무·등기 실비 — `rules/cost.csv` (0건)

| 항목 | 필요한 값 | 출처 |
|---|---|---|
| `국민주택채권` | 시가표준액 구간별 매입률 × 즉시매도 할인율 | 주택도시기금법 시행령 [별표] + 당일 할인율 |
| `등기신청수수료` | 전자표준양식 기준 건당 수수료 | 등기사항증명서 등 수수료규칙 |
| `증명서발급` | 등본·초본 등 발급비 | 정부24 수수료 |

채권 할인차손은 **날마다 변하므로 `verification=ESTIMATED` 가 정답**이다.

### 1-4. 다주택·규제지역 취득세 중과 — `rules/tax.csv` (0건)

지금은 **취득 후 2주택 이상이면 취득세가 확인 불가**다(0원으로 세지 않는다).
지방세법 제13조의2 원문을 보고 조합별로 넣어야 한다. 넣을 자리를 주석으로 만들어 뒀다.

- 1세대 2주택 (조정 / 비조정)
- 1세대 3주택 이상 (조정 / 비조정)
- 법인
- 일시적 2주택 (처분기한 충족 시 1주택 세율)

### 1-5. 양도소득세·지방소득세 — `rules/tax.csv` (0건)

없으면 **EXPECTED_ROE 가 나오지 않는다**(매도비용이 확인 불가라서).
1세대1주택 비과세 요건과 보유기간별 기본세율·누진공제가 필요하다.

### 1-6. 재산세·종합부동산세 — `rules/tax.csv` (0건)

PHASE 7 현금흐름·보유비용에 필요하다. 지금은 보유비용이 확인 불가다.

### 1-7. 서울·경기 중개보수 조례 — `rules/cost.csv`

지금 들어 있는 건 **인천 조례뿐**이다. 서울·경기 물건은 중개보수가 확인 불가다.

## 2. 값은 들어 있으나 원문 확인이 필요한 것 (NEEDS_VERIFICATION)

계산은 되지만 결과가 **'예상 실투자금'** 으로만 표시된다.
원문을 확인하고 `verification` 을 `VERIFIED` 로 바꾸면 '확정' 이 된다.

| 규칙 | 현재 값 | 근거 | 확인할 것 |
|---|---|---|---|
| `농어촌특별세 / rural/주택/85초과` | 취득가액 × 0.2% | 농특세법 §5① [별표] 제6호 | 조문이 "표준세율 2%로 산출한 취득세액의 10/100" 인지. 그러면 0.2% 가 맞다 |
| `농어촌특별세 / rural/주택/85이하` | 0원 (비과세) | 농특세법 §4 제11호 | 국민주택규모 서민주택 비과세 범위. 전용 85㎡ 기준이 맞는지 |
| `부가가치세 / vat/기본` | 10% | 부가가치세법 §30 | 세율. 간이과세 중개사무소는 다를 수 있음 |
| `인지세 / stamp/*` | 2만~35만원 정액 | 인지세법 §3① [별표], §6 제5호 | 구간별 금액. 주택 1억 이하 비과세 여부. **매도·매수인 절반 부담 관행 반영 여부** |

> 인지세는 현재 **전액**을 매수인 부담으로 잡아 보수적으로 계산한다.
> 절반만 부담하는 게 실제라면 `fixed_amount` 를 절반으로 고치세요.

## 3. 이미 확인된 것 (VERIFIED — 종인님이 이전에 확인)

| 규칙 | 값 | 근거 |
|---|---|---|
| 취득세 1주택 6억 이하 | 1% | 지방세법 §11①8 가목 |
| 취득세 1주택 6~9억 | `(취득가액×2÷3억−3)%` 점증 | 지방세법 §11①8 나목 |
| 취득세 1주택 9억 초과 | 3% | 지방세법 §11①8 다목 |
| 지방교육세 (3구간) | 취득세율의 1/10 | 지방세법 §151①1 |
| 중개보수 인천 (6구간) | 0.6% / 0.5% / 0.4% / 0.5% / 0.6% / 0.7% | 인천광역시 조례 |
| 토지거래허가구역 인천 외국인 (9건) | — | 인천시 고시 |

## 4. 확인 순서 (수익 영향이 큰 것부터)

1. **`rules/loan.csv` LTV·DSR** — 이게 없으면 "내 현금으로 어디를 살 수 있나"가 아예 안 나온다
2. **다주택 취득세 중과** — 2주택 이상 시나리오가 전부 막혀 있다
3. **법무사 보수표** — 금액은 작지만 실투자금이 '확정'이 되려면 필요하다
4. **양도소득세** — EXPECTED_ROE(내 돈 대비 수익률)의 전제
5. **농특세·인지세 원문 대조** — 이미 계산은 되지만 '예상' 딱지를 떼려면 필요하다
6. 재산세·종부세 — PHASE 7 현금흐름에서 쓴다

---

## 5. 확인한 뒤 하는 일

```bash
# 1) 파일을 고친다 (rules/loan.csv 의 '#' 을 지우고 값을 채운다)
# 2) 다시 넣는다
python -m apt_engine.cli rule import loan rules/loan.csv
python -m apt_engine.cli rule status          # 채워진 정도 확인

# 3) 확인만 했다면 (값은 이미 맞음) verification 만 올린다
python -m apt_engine.cli rule verify tax --id 7 --date 2026-09-01
```

`rule import` 는 **INSERT** 라 같은 파일을 두 번 넣으면 행이 중복된다.
다시 넣을 때는 해당 표를 먼저 비우거나, 새 규칙 행만 담은 파일을 넣으세요.
