## A. 기한이 걸린 것 — 지금 확인 ★

### A-1. 인천 토지거래허가구역 재지정 여부 (2026-08-25 만료)

`rules/permit.csv` 의 인천 외국인 토허 9건이 **2026-08-25 로 지정기간이 끝났다.**
오늘(2026-08-31) 기준으로 엔진은 그 지역을 **"토허 아님"** 으로 판정한다.

```bash
python -m apt_engine.cli regulation "단지명"     # 지금 판정 확인
```

실제로 재지정됐다면 지금 계산이 전부 틀린다(전세 승계 가능 여부 → 실투자금).
인천시 고시를 확인해서:

- **재지정됐으면** → `rules/permit.csv` 에 새 기간의 행을 **추가**한다
  (기존 행을 고치지 말 것. 과거 시점 분석이 틀어진다)
- **해제됐으면** → 그대로 두면 된다. 기존 행이 이력으로 남는다

이 표는 `effective_to` 가 NOT NULL 이라 "지정기간이 끝났는데 현재 토허로 표시"
하는 사고는 구조적으로 막혀 있다. 대신 **재지정을 놓치는 사고**는 사람이 막아야 한다.
1년에 한 번 재확인 일정을 잡아두시면 좋겠다.

## B. 실투자금을 '확정'으로 만드는 것

지금은 모든 케이스가 **"예상 실투자금"** 이다. 아래 3개가 확인 불가라서다.

### B-1. 법무·등기 실비 3종 ← 이것만 채우면 일반세율 케이스는 '확정'이 된다

`rules/cost.csv` 안에 주석으로 채울 자리를 만들어 뒀다. `#` 만 지우고 값 입력.

| 항목 | 필요한 값 | 출처 | 적정 verification |
|---|---|---|---|
| `등기신청수수료` | 전자표준양식 건당 수수료 | 등기사항증명서 등 수수료규칙 (iros.go.kr) | `VERIFIED` |
| `증명서발급` | 등본·초본 등 발급비 | 정부24 | `ESTIMATED` |
| `국민주택채권` | 매입률 × 즉시매도 할인율 | 주택도시기금법 시행령 [별표] + 당일 할인율 | **`ESTIMATED`** (매일 변함) |

### B-2. 다주택 중과 건의 지방교육세

취득세 8%·12% 건의 지방교육세 산식을 아직 못 받았다.
**CASE 4·5·6 에서 지방교육세가 "확인 불가"** 로 나온다(0원으로 세지 않음).
일반세율 건(CASE 1·2·3)은 정상이다. → `rules/tax.csv` 주석 1번

### B-3. 농어촌특별세 85㎡ 초과 세부 산식

지시대로 기존 0.2% 를 유지하되 `NEEDS_VERIFICATION` 으로 뒀다.
특히 **중과세율(8%/12%) 건에서 산식이 다를 수 있다** — 지금은 중과 건에도 0.2% 가 붙는다.

## C. 대출 한도를 정확하게 만드는 것

### C-1. LTV — 비규제 / 생애최초 / 다주택 / 처분조건 없는 1주택

받은 건 **규제지역 무주택·처분조건부 1주택의 40%** 뿐이다. 나머지 조건에서는
`LTV 한도` 가 확인 불가라, 엔진이 **담보가액(집값)** 을 산술적 상한으로만 쓴다.

> 담보가액은 정책이 아니라 "집값보다 많이 빌릴 수는 없다"는 산술이다.
> 실제 LTV 는 훨씬 낮으므로 **지금 실투자금은 실제보다 작게 나올 수 있다.**

`rules/loan.csv` 주석 1~3번의 `<value>` 만 채우면 된다.
비규제 LTV 는 지시문에 "70% → 40%" 라고 적혀 있었지만, 그 70% 를 현재 유효한
규칙으로 확인해 주시기 전까지는 넣지 않았다.

### C-2. 백테스트용 과거 정책 (나중에)

지금 규칙은 전부 **최근 시행일 기준**이다. 2021년 물건을 분석하면
"규칙 없음 → 확인 불가" 가 나온다. 백테스트를 실제로 돌릴 때 채우면 된다.

| 표 | 지금 시작일 | 그 이전을 보려면 |
|---|---|---|
| 취득세·지방교육세 | 2026-07-01 | 그 시점 세법 행 추가 |
| LTV·스트레스 DSR·절대한도 | 2025-10-16 | 그 시점 정책 행 추가 |
| DSR | 2022-07-01 | — |

**기존 행을 덮어쓰지 말고 `effective_to` 를 채운 뒤 새 행을 추가**하세요.
덮어쓰면 과거 분석이 조용히 틀려집니다.

## D. 수익률·랭킹을 열려면

### D-1. 양도소득세 · 지방소득세

없으면 매도비용이 확인 불가라 **EXPECTED_ROE 가 나오지 않는다.**
그 단지는 랭킹에서 `comparable=False` 로 빠진다. → `rules/tax.csv` 주석 4번

- 1세대1주택 비과세 요건 (보유기간·고가주택 기준)
- 보유기간별 기본세율·누진공제
- 지방소득세 (양도세액의 10%)

### D-2. 재산세 · 종합부동산세 · 공정시장가액비율 · 장기보유특별공제

PHASE 7 이 이걸 기다린다. 없으면 보유세가 확인 불가라 **연도별 순현금흐름과 IRR 이
나오지 않는다**(급하면 `cashflow --holding-cost` 로 연간 보유비용을 직접 넣으면 된다).

- 재산세·종부세 세율 → `rules/tax.csv` 주석 5번
- **공정시장가액비율** — 공시가격 → 과세표준 환산 비율. 없으면 공시가격을 그대로
  과세표준으로 쓰지 않는다(세금이 과대계상된다)
- **장기보유특별공제율** — 보유기간별. 없으면 양도세가 과대계상되므로 '확인 불가' 로 둔다
- 양도소득 **기본공제** — `rule_key` 에 '기본공제' 가 들어간 양도소득세 행으로 넣는다

## G. 도메인 지식 입력 (PHASE 4~6 이 이걸 기다린다)

코드는 다 됐고 값만 비어 있다. 급한 순은 아니지만, 넣는 만큼 분석이 깊어진다.

| 무엇 | 명령 | 없으면 |
|---|---|---|
| **가격사다리** | `ladder template/import` | 비교단지가 안 잡혀 상대가치 분석 불가 |
| 교통사업 단계 | `transit template/import` | 교통호재 확인 불가 |
| 입주물량 | `supply template/import` | 공급 분석 불가 |
| **대지면적**(건축물대장) | `redev template/import landarea` | 재건축 사업성 **전부** 불가 |
| 정비사업 단계 | `redev template/import project` | 재건축 단계·지연위험 확인 불가 |
| 평당 공사비 | `redev template/import cost` | 추가분담금 계산 불가 |
| 단계별 소요기간 | `redev template/import duration` | 사업기간이 "확인 불가" |

**G-1.** 가격사다리 서식(`ladder template`)에 종인님이 주신 4개 축(서남권·경부축·
안양권·서북권)이 들어 있는데 **부천·광교·동탄의 `lawd_cd` 가 비어 있다.** 채워주세요.

**G-2.** 재건축은 **상위 후보만** 조사하면 된다:
```bash
python -m apt_engine.cli redev screen --limit 100   # 1차 자동 선별
python -m apt_engine.cli redev mark "단지명" --status 조사중
```
1차는 연식·용적률·대지지분만 보고 금액은 만들지 않는다.
상위 50~100개만 건축물대장·정비계획을 수기로 채우면 된다.
