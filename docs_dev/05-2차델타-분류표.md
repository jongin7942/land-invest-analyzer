## 3. 기존 로직을 수정한 것

| 무엇 | 전 | 후 | 왜 |
|---|---|---|---|
| `PriceBands` | 3구간 (Strong/Fair/DoNot) | **5구간** + `attractiveness()` | §2 — 순위가 아파트가 아니라 아파트×가격에 붙어야 함 |
| `split()` | Stage 기준만 | `gates=` 인자 추가, `pure`·`gate_blocked` 반환 | §5 — 토허를 감점이 아니라 문으로 |
| `DATED_TABLES` | 기존 표만 | 신규 3개 등록 | 소득통계는 **발표 시차**가 있어 미래 데이터가 샐 수 있음 |

기존 호출부는 `gates` 를 안 주면 예전과 똑같이 동작한다 — 깨뜨리지 않았다.

## 4. 아직 데이터가 부족한 것

| 필요한 데이터 | 왜 | 없으면 |
|---|---|---|
| **지역 고용·사업체·소득** (`region_income`) | 국토부 실거래에는 소득 정보가 없다 | Income Flow 가 **확인 불가**. 0 으로 채우지 않는다 |
| **사다리 관측** (`migration_flow`) | 축(`ladder_axis`)은 있으나 시점별 관측이 비어 있음 | Migration Flow 확인 불가 |
| **토허 유예 여부** | 개별 구역 고시를 봐야 안다 | 실거주 의무 구역은 **BLOCKED** (안전 쪽) |
| **주변 대표 신축 미래가격** | 정비사업 완공가치의 기준 | 완공가치 계산 안 함 |
| 비교군 정상 가격차 | 상품성 차이만큼은 저평가가 아님 | Relative Stretch 신뢰도 40% 감점 |

## 5. 아직 백테스트가 필요한 것

- §44 2019 / 2021 / 2023 연도별 시나리오 (수집 완료 후)
- `INCOME_WEIGHT` 지표별 가중치 — 지금은 상식적 초기값이지 학습값이 아님
- `PENALTY` 품질 감점 폭 — 가정이지 관측이 아님
- 가격 5구간의 경계(0.15 / 0.50 / 0.70 / 0.88 / 1.00)
- `MIN_UPPER_RISE` · `MIN_GAP` · `MIN_OVERLAP` 사다리 인정 기준
