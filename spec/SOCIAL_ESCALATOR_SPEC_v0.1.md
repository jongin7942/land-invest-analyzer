## 4. 지표 정의 (사전 고정)
평가일 t = 각 연도 6월, 이동자료는 연도 t−1.
1) **기대 이동량**: log F(o,d) ~ log(출발지 총전출) + log(도착지 총전입 재고 대리 = 도착지 1,000세대+ 단지 세대 합) + log(거리 km+1) + 도착지 급지 중앙값. ridge(λ=1), 같은 해 자료로만 적합. `excess(o,d) = log F(o,d) − log F̂(o,d)`.
2) **선택 집중량** `bpc_flow(j)` = Σ_o [F(o,d(j)) × compat(o, j)] 를 log1p. `compat(o,j)` = 출발지 o 의 ㎡단가 중앙값이 후보 j 의 ㎡단가의 0.8배 이상일 때 1, 아니면 0(예산상 하향·수평 이동만 유효수요로 셈). 출발지 가격은 t−1 시점 관측치.
3) **초과 집중량** `bpc_excess(j)` = Σ_o [excess(o,d(j)) × compat(o,j)] / Σ_o compat(o,j).
4) **출발지 다양성** `eff_origins(j)` = exp(−Σ a(o,j) log a(o,j)), a = compat 가중 유입 비중. 집계단위 민감도는 시도 단위로 재계산해 확인.
5) **최대 집단 의존도** `top_origin_share(j)`.
6) **가격 상승 시 선택 유지** `retention10(j)` = compat 을 j 가격 ×1.1 로 다시 계산한 bpc_flow ÷ 원래 bpc_flow. 분모 0 이면 UNKNOWN.
